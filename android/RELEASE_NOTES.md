# Fable II for Android 1.0.0

<!-- Draft text for the GitHub release. Attach Fable2-Android-1.0.0-release.apk. -->

A native Android build of the Fable II recompilation. **Bring your own game:** you need
an ISO of a supported Fable II disc. The APK contains no game content.

## Install
1. Download **Fable2-Android-1.0.0-release.apk** below and install it.
2. Copy your Fable II ISO to the device.
3. Open the app, tap **Select game ISO**, choose the file and wait for it to install.
4. Tap **Play**.

Requires Android 12+, a 64-bit device and about 7 GB free (plus the ISO while installing).
An Adreno 7xx GPU (Snapdragon 8 Gen 1 or newer) is strongly recommended.

## Highlights
- Install straight from the ISO, no PC needed
- Resolution scale, MSAA, triple buffering and GPU driver settings
- Controller button remapping
- On-screen touch controls with a drag-and-drop layout editor
- One-tap save backup
- Bundled Mesa Turnip driver for Adreno
- About 29 FPS while moving on an AYN Thor (Snapdragon 8 Gen 2) at native 720p

## Supported versions
GOTY USA/Europe, Germany, France, Italy, Russia and Spain. German retail/TU1, Japan,
Asia and Latin America are not supported yet.

## Known issues
- Short hitches the first time you visit an area while shaders compile. They disappear
  on later visits and launches.
- Just under a locked 30 FPS on the Thor. Expect lower on slower GPUs.
- 2x and 3x resolution scale are experimental and far from playable speed on current handhelds.
- Uninstalling the app deletes your saves. Use **Back up saves** first.
